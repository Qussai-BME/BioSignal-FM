Overview

A modular research workflow for heterogeneous biosignal modalities.

BioSignal-FM V4 provides canonical signal contracts, explicit provenance, modality-aware preprocessing, trainable representation components, optional fusion, and protocol-aware evaluation for EMG, EEG, ECG, experimental ECoG/iEEG, and legacy-compatible fNIRS workflows. It is an Apache 2.0 open-source Python package designed for auditable research engineering. It does not claim a validated foundation model, real-data benchmark performance, zero-shot transfer, clinical utility, or regulatory clearance.

Key Features

Engineered across three axes.

Scientific rigor, engineering quality, and reproducibility are not afterthoughts — they are the product.

Scientific

Protocol-aware, evidence-bound, and reproducible by design.

  • Protocol templates for prespecified hypotheses, splits, metrics, baselines, and evidence review.
  • LOSO + LODO cross-validation as primary and secondary protocols.
  • Friedman + Nemenyi + Wilcoxon-Holm-Šídák multiple-comparison suite with the correct Šídák formula.
  • BCa bootstrap CIs (10,000 resamples) and Hedges' g effect sizes.
  • Mixed-effects models with subject & session random intercepts.

Engineering

Optional export and serving capabilities with operator-controlled deployment.

  • Dynamic int8 quantization is available where supported; latency must be measured on the target hardware.
  • DistilledFoundationModel variant (6 layers, d_model=256) for edge deployment.
  • ONNX export (verified numerical parity) plus FastAPI REST & WebSocket serving, Docker deployment.
  • Configurable model components support research comparisons; an available component is not a performance claim.
  • Per-modality patch embeddings via Conv1d, since channel counts differ.

Quality

Test-backed, provenance-aware, and release-reviewed.

  • Release verification covers tests, linting, formatting, typing, documentation, dependency audit, and clean-core installation.
  • SHA-256 run manifest linking every output to its env fingerprint & git HEAD.
  • Informational governance material states research-only boundaries and does not establish regulatory readiness.
  • Apache-2.0 licensed, fully open-source, CPU-reproducible end-to-end.
  • Model Card and GDPR data-protection appendix included.

Statistical Rigor

Six layers of inferential defense.

No single test carries the argument. Each layer guards a distinct failure mode common in biosignal ML papers.

01

Friedman test

Non-parametric omnibus test across all methods and folds. Detects whether any method differs without assuming normality.

02

Nemenyi post-hoc

Critical-difference diagram on average ranks. Visualizes pairwise significance when Friedman rejects equivalence.

03

Wilcoxon-Holm-Šídák

Pairwise signed-rank with the correct step-down correction 1-(1-p)^(m-k) — not Bonferroni-Holm.

04

BCa bootstrap

Bias-corrected accelerated confidence intervals over 10,000 resamples for every reported metric.

05

Hedges' g

Small-N corrected Cohen's d effect size. Reports magnitude, not just significance, for every comparison.

06

Mixed-effects model

accuracy ~ method + (1|subject) + (1|session) via statsmodels. Reports ICC and β coefficients.

Limitations

Eight honest caveats.

Stating limitations up front is a feature, not a liability. This is research-grade software, not FDA-cleared SaMD.

No real-data benchmark in this release

V4 verifies software contracts and synthetic smoke paths. A benchmark requires licensed real data, locked splits, baselines, and reproducible artifacts.

No completed pretraining evidence

Available model components do not establish a learned general representation without documented real-data training and evaluation.

No baseline-comparison claim

Any comparison must be prespecified, real-data based, versioned, and reported with appropriate uncertainty.

No validated foundation-model claim

V4 provides research architecture and testable components; broad representation-learning or transfer claims require real data and independent evaluation.

Research use only

This is research software, not a clinical device. Informational regulatory material does not establish clearance, certification, or clinical suitability.

Small-N statistics

5 subjects × 4 classes × 5 samples per class per modality. Effect sizes and CIs reflect this limited sample.

Single-environment reproducibility

SHA-256 manifests pin one environment. Multi-site external validation is future work pending real-data access.

Hypotheses not yet tested

H1/H2/H3 are pre-registered but unfalsified until real pretraining + real datasets are available. The framework is final; the verdict is pending.
