**الإصدار:** `4.0.3`  
**المصدر:** commit موثق في `FINAL_RELEASE_MANIFEST.json`  

منصة بحثية متعددة الوسائط لإشارات EMG وEEG وECG، تضم عقوداً وطبقات معالجة ونماذج وتقييماً ونشرَ بحثياً محلياً.

تتضمن الحزمة توزيعات Python (`wheel` و`sdist`)، ولقطة مصدر نظيفة، وسجل إصدار نهائي، وملف SHA-256، وسجلات تحقق الاختبار والبناء والتثبيت السريع.

## التحقق

```bash
sha256sum -c CHECKSUMS.sha256
```
